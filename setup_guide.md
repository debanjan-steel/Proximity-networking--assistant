# Proximity Networking App - Setup & Deployment Guide

This guide walks you through setting up the **Proximity Networking App** in Google Sheets with Google Apps Script and the Groq API.

---

## Step 1: Create and Name Your Google Sheet
1. Open [Google Sheets](https://sheets.new) and create a new spreadsheet.
2. Rename the spreadsheet to **`Proximity Networking App`**.
3. Rename the active sheet tab at the bottom to **`Targets`**.

---

## Step 2: Configure Column Headers & Formatting

Set up the exact 10 columns in Row 1 of the **`Targets`** tab:

| Column | Header Name | Type | Notes / Validation |
| :---: | :--- | :--- | :--- |
| **A** | `Target_Name` | Text | Full name of contact |
| **B** | `Role` | Text | Job Title (e.g., *Senior IoT Analytics Manager*) |
| **C** | `Company` | Text | Employer (e.g., *TechCorp*) |
| **D** | `LinkedIn_URL` | Text / URL | Profile link |
| **E** | `Is_CMI_Alumni` | Checkbox | Insert via: `Insert -> Checkbox` |
| **F** | `Networking_Objective` | Dropdown | `Data -> Data validation` -> List: `Employment, Collaboration` |
| **G** | `Tier` | Computed | Auto-populated by script (`Tier 1`, `Tier 2`, `Tier 3`) |
| **H** | `Recommended_Asset` | Computed | Auto-populated by script |
| **I** | `Icebreaker_Draft` | Computed | Auto-generated by Groq API (<60 words) |
| **J** | `Status` | Status | Auto-updated: `Processing...`, `Generated`, `Error` |

*(Tip: You can also click **`🚀 Proximity Networking -> ⚙️ Initialize Sheet Template & Headers`** once the script is added to format automatically).*

---

## Step 3: Install the Google Apps Script Code
1. In your Google Sheet, click **`Extensions` -> `Apps Script`**.
2. Replace all existing contents of `Code.gs` with the complete code from [`code.gs`](file:///c:/Users/deban/OneDrive/Desktop/Anti%20Gravity%20projects/code.gs).
3. Click the **Save** icon (💾) or press `Ctrl + S` / `Cmd + S`.
4. Rename the Apps Script project to **`ProximityNetworkingEngine`**.

---

## Step 4: Configure Your Groq API Key
You can configure your key securely without hardcoding it:
1. Generate an API Key from the [Groq Console](https://console.groq.com/keys) (your key will start with `gsk_...`).
2. Reload your Google Sheet tab in the browser.
3. You will see a new menu: **`🚀 Proximity Networking`**.
4. Click **`🚀 Proximity Networking -> 🔑 Set Groq API Key`**.
5. Paste your Groq API key and click **OK**.

---

## Step 5: Run the Verifier & Automated Tests
1. In the menu, click **`🚀 Proximity Networking -> 🧪 Run QA Verifier Test Suite`**.
2. Grant authorization when prompted by Google.
3. The script will execute both **Scenario 1** (Employment / Tier 3 / IoT RUL Copilot) and **Scenario 2** (Collaboration / Tier 1 / CMI Alumni / Streamlit) and display a success popup confirming that all verifier conditions pass!

---

## Step 6: Deploy Web App API (For Live Antigravity Chat Sync)
To allow Antigravity to directly read your Google Sheet, summarize target rows, and write summaries back automatically:

1. In the Apps Script editor, click the blue **Deploy** button (top right) $\rightarrow$ **New deployment**.
2. Select type: **Web app** (gear icon $\rightarrow$ Web app).
3. Set:
   - **Description**: `Antigravity Live Sheet Sync`
   - **Execute as**: `Me (<your_email>)`
   - **Who has access**: `Anyone` *(required for webhook access)*
4. Click **Deploy** and copy the **Web app URL** (looks like `https://script.google.com/macros/s/.../exec`).
5. Share the URL with Antigravity in chat or use [`sheet_sync.py`](file:///c:/Users/deban/OneDrive/Desktop/Anti%20Gravity%20projects/sheet_sync.py):
   ```bash
   # Read all pending rows from your live sheet:
   python sheet_sync.py --url "YOUR_WEB_APP_URL" --read-pending

   # Push AI summary to a specific row (e.g. Row 2):
   python sheet_sync.py --url "YOUR_WEB_APP_URL" --update-row 2 --draft "Generated Icebreaker text..."
   ```
